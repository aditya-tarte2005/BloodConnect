BLOODCONNECT FRONTEND DEMO

1. Extract this folder.
2. Open the extracted folder in VS Code.
3. Install the VS Code extension "Live Server" (by Ritwick Dey).
4. Right-click index.html -> Open with Live Server.
5. The dashboard will open in your browser.

This is a frontend-only demo using HTML, CSS and JavaScript.
The numbers are dummy data for now. Later they can be replaced with data from your Java/Spring Boot REST APIs.
