# BloodConnect

BloodConnect is a Blood Bank Management System designed to manage donors, hospitals, blood inventory, blood requests, transactions, notifications, settings, and reports.

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- Maven

### Database
- H2 Database (Development)
- MySQL (Production)
